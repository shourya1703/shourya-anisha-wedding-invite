# Shourya & Anisha — Interactive Wedding Invitation

A mobile-first React/Vite single-page wedding invitation designed to feel like a premium digital wedding card.

## Included
- Opening invitation cover with Ganesha and the provided Sanskrit shlok
- Scroll-based paper/card experience
- Haldi — 1 December 2026, 12 PM onwards
- Sangeet — 1 December 2026, 8 PM onwards
- Wedding — 2 December 2026, 7 PM onwards
- Venue/address only (no hotel image)
- Original browser-generated wordless ambient instrumental (no copyrighted audio file)
- Responsive mobile/desktop layout
- Google Maps link
- No backend and no paid services required

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

The deployable files are created in `dist/`.

## Free hosting

### Vercel
1. Create a GitHub repository and upload this project.
2. Import the repository at Vercel.
3. Vercel detects Vite automatically.
4. Build command: `npm run build`
5. Output directory: `dist`

### Netlify
Drag the `dist/` folder into Netlify Drop after running `npm run build`.

### GitHub Pages
This can also be deployed as a static Vite site; if you use a project repository rather than a custom domain, set Vite's `base` to the repository name before building.
